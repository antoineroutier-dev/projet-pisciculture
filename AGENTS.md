## Exception de visibilité (décision du propriétaire, 8 octobre 2026)

Ce dépôt est **public** volontairement, pour servir GitHub Pages. Le push normal y est
autorisé malgré l'exigence de dépôt privé de [GIT-WORKFLOW.md](GIT-WORKFLOW.md) : vérifier
qu'il s'agit bien de `antoineroutier-dev/projet-pisciculture` et qu'il est resté public.
Tout ce qui est poussé devient public : audit renforcé avant chaque push, aucune donnée
privée, aucun secret, aucun document personnel. Cette exception ne s'applique à aucun autre dépôt.
